    openclaw windows WSL2 平台部署说明：（macOS或linux部署类同）

    前的准备工作

    1. node.js 22+
    2. git

    wsl –install //wsl安装
    wsl –version //查看版本

    Windows(PowerShell) 全局安装设置向导

    iwr -useb https://openclaw.ai/install.ps1 | iex

    进入初始化向导 openclaw onboard

    1. 安装产品模型选择Qwen
    2. 频道选择国内Feishu
    3. 其他的继续学习和钩子后面再选

    初始化完成查看 openclaw状态

    1. openclaw –version //查看版本
    2. openclaw gateway status //查看网关状态

    注意：http://127.0.0.1:18789/ 第一次登录会提示你输入Token，使用openclaw dashboard –no-open 来显示

    OpenClaw接进飞书

    前提准备

    1. OpenClaw
    2. 飞书账号

    Step.1:在飞书开放平台创建应用

    首先打开飞书开放平台：
    https://open.feishu.cn/app 登录后进入开发者后台。

    接下来：点击 创建应用 → 企业自建应用

    然后填写应用信息：
    应用名称（例如：OpenClaw AI 助手）描述（随便写即可）

    创建完成后，会进入应用详情页。在凭证与基础信息页面，你会看到两个非常重要的信息：

    App ID

    App Secret

    把它们保存下来，后面会用到。

    Step.2:开启机器人能力

    在左侧菜单中找到：应用能力 → 添加应用能力

    选择：机器人 启用即可。

    这一步的作用是：让你的应用可以在飞书里充当聊天机器人。

    Step.3:配置应用权限

    很多人看到权限配置就会头大，其实这里非常简单。

    飞书支持 批量导入权限配置。

    进入：

    权限管理 → 批量导入

    然后把官方推荐的 JSON 权限配置直接粘贴进去即可

    {
    “scopes”: {
    “tenant”: [
    “contact:user.base:readonly”,
    “contact:user.employee_id:readonly”,
    “contact:user.id:readonly”,
    “contact:contact.base:readonly”,
    “im:chat”,
    “im:chat.access_event.bot_p2p_chat:read”,
    “im:chat.members:read”,
    “im:chat.moderation:read”,
    “im:chat.tabs:read”,
    “im:chat.tabs:write_only”,
    “im:chat.top_notice:write_only”,
    “im:chat:moderation:write_only”,
    “im:chat:operate_as_owner”,
    “im:chat:read”,
    “im:chat:readonly”,
    “im:chat:update”,
    “im:message”,
    “im:message.group_at_msg:readonly”,
    “im:message.group_msg”,
    “im:message.p2p_msg:readonly”,
    “im:message.pins:read”,
    “im:message.pins:write_only”,
    “im:message.reactions:read”,
    “im:message.reactions:write_only”,
    “im:message.urgent”,
    “im:message.urgent.status:write”,
    “im:message:readonly”,
    “im:message:send_as_bot”,
    “im:message:send_multi_depts”,
    “im:message:send_multi_users”,
    “im:message:send_sys_msg”,
    “im:message:update”,
    “im:resource”,
    “im:url_preview.update”,
    “im:user_agent:read”,
    “passport:session_mask:readonly”
    ],
    “user”: []
    }
    }

    这样系统会自动帮你开启所需权限。这种方式比一个个勾选要方便得多，也不容易漏掉关键权限

    Step.4:配置事件订阅

    接下来需要告诉飞书一件事：如果有人给机器人发消息，请通知 OpenClaw。
    进入：

    事件与回调

    然后选择：

    使用长连接接收事件

    这里非常关键。

    因为我们使用的是 WebSocket 长连接模式，好处非常明显：

    不需要公网服务器
    不需要域名
    本地电脑就可以直接运行
    保存的时候，如果提示：应用未建立长连接
    不用担心，这是因为 OpenClaw 还没有配置飞书渠道。

    先把这个页面放着，我们继续下一步。

    Step.5:在OpenClaw中添加飞书渠道

    现在回到终端。

    运行命令：openclaw channels add

    然后按照提示依次选择：

    Feishu

    输入刚刚保存的 App ID和App Secret

    选择 China

    其他选项按默认即可，最后一定需要选择Finnish完成。

    配置完成后，重启网关：openclaw gateway restart 如遇到重启不起来，通过手动运行openclaw gateway run

    Step.6:回到飞书完成事件订阅

    回到刚才的飞书后台页面。再次点击保存。这次就不会再报错了。

    然后新增一个事件：im.message.receive_v1

    这个事件的作用是： 当用户给机器人发送消息时，通知 OpenClaw。

    Step.7:发布应用

    配置完成后，还需要发布一次应用。

    进入：版本管理与发布

    点击：创建版本

    填写：版本号 更新说明 然后点击发布。

    Step.8:测试机器人

    现在打开飞书。

    搜索你刚刚创建的机器人名称。

    给它随便发送一条消息。 第一次聊天时，机器人会返回一个 配对码

    回到终端执行：openclaw pairing approve feishu <配对码>

    批准之后，再发消息试试。

    这时候你会发现： AI 已经可以在飞书里正常回复你了。

    整个体验就像和同事聊天一样自然。

    OpenClaw接进Skill技能

    Tavily 前期准备

    1. OpenClaw 环境 - 已运行的 OpenClaw 实例
    2. Tavily 账号 - 访问 tavily.com 注册账号
    3. 获取 API Key - 注册后在 dashboard 中获取 API Key

    Step.1: CLI安装Tavily

    openclaw plugins install openclaw-tavily
    安装完成后，重启Openclaw网关（openclaw gateway restart）

    Step.2: 配置API KEY

    1. 登陆openclaw控制台 http://127.0.0.1:18789
    2. openclaw -> 技能选项找到tavily 输入API Key
    1. openclaw直接对话“查找相关最新新闻简报”
